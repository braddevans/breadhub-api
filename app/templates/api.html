Image grid

Open image grid

Request

POST /api/imagegrid/generate multipart/form-data

Upload images as repeated images fields. They are laid out in the smallest square grid that fits them, so 5 images make a 3×3 grid.

Response

Image 200

The finished grid as a PNG (image/png).

Limits

  • Request body{{ max_upload_mb }} MB
  • Output size{{ '{:,}'.format(max_output_pixels) }} px

Errors 400 / 413 / 500

Same JSON shape as the barcode API. 413 means the upload is over the request body limit.
